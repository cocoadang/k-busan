## 원인과 수정

RSS description이 기사 제목을 반복했는데 실제 본문처럼 분석기에 전달됐다. Google News 공개 링크의 언론사 주소 해석 및 본문 읽기를 추가했다. 모든 리다이렉트에 명시적 HTTPS 호스트 제한, 읽기 시간·크기 제한을 적용하며 접근 제한을 우회하지 않는다. 네이트 EUC-KR 인코딩, 연합뉴스 요약/본문 구분, 매체별 본문·발행일 영역도 처리했다. 본문은 비공개 서버 캐시에 보존하고 공개 사건에는 제한된 인용·본문 해시·원문 URL만 남긴다.

기사 발행일과 사건일은 별도다. 사건일 인용은 본문에 실제로 있어야 하며, 전날·지난 4일 같은 표현은 원문 발행일의 한국시간에 대조한다. 월만 나온 일정에 1일을 임의로 붙이지 않는다. 날짜 근거가 부족한 분석은 유료 재시도를 반복하지 않고 검토로 넘긴다. 검토 종결은 completed와 다른 closed 상태로 기록하며, 사유와 출처를 보존하고 화면에 따로 표시한다.

## 운영 적용·복구 원칙

운영 적용 전 읽기 전용 계획 검증을 실행했다. 대상 16개 출처에만 의존하는 잘못된 날짜·추정·중복 사건은 비공개 analysisReviewCorrections에 원본을 보존한 뒤 공개 사건 목록에서 철회한다. 다른 출처가 남는 사건은 해당 출처만 제거한다. 큐 원본도 변경 전에 같은 교정 이력에 보존한다. 기존 수집 잠금 아래 실행하고 원문 fingerprint·본문 해시·날짜 인용을 재검증한다. 실제 사건 저장·주기 이력 쓰기가 끝나야 ready 결과가 completed가 된다.

검증과 적용은 Telegram 키가 없는 별도 작업 및 인증된 notify=false 운영 경로를 사용한다. 운영 결과는 적용 후 별도 acceptance JSON에 기록한다. 기사 본문 전체 및 비밀 값은 저장소에 올리지 않는다.

### 출처 저장 경로 추가 교정

최종 Firestore 원문 대조에서 대표 출처와 `sources[0]`이 같은 객체일 때, 기존 정제 함수가 이를 순환 참조로 오판해 첫 번째 출처를 누락시키는 문제를 발견했다. 실제 순환 참조는 제거하되 동일 객체가 여러 경로에서 참조되는 경우는 모두 보존하도록 수정했다. 같은 URL에 더 최신의 검증된 본문 근거가 들어오면 기존 제목 요약만 남지 않도록 출처 병합도 보완했다. 실제 저장 경로 회귀 검사를 추가하고, 이미 검증한 10개 입력(기존 9건 및 후속 1건)을 AI 재호출 없이 ready 상태로 재저장해 출처 목록까지 다시 대조한다.


## 적용 완료 결과

운영 버전 `38dfe1d`(관련 PR #14, #15)에 반영했다. 기존 16건은 9건 근거 반영·7건 사건 미등록 검토 종결로 정리했고, 과천5단지의 11월6일 후속 1건도 반영했다. 현재 큐는 완료81·검토종결7·대기0·재시도0·확인필요0이다. 날짜와 각 출처의 본문 해시·인용이 실제 Firestore 기록에 보존되는지 독립 조회로 대조했다. 수동 확정 정비이력과 뉴스 사건이 별도 저장되는 경우에도 같은 검증 날짜와 출처 근거를 보존했으며 기존 공식 정비이력은 유지했다.

기존 추정·잘못된 날짜·중복 출처에 의존한 사건 42개와 원래 큐 16개는 교정 이력에 원본을 보존한 뒤 정정했다. 출처 재저장 전 상태도 10개 별도로 보존했다. UI에서 검토종결7건이 완료와 구분되어 표시되는 것을 확인했다. 임시 검증 작업은 삭제했고 기사 비공개 캐시에 30일 TTL 정책을 활성화했다.

검증 중 Telegram 발송은 0건이다. 최종 출처 재저장 주기는 AI 호출도 0건이다. 전체183개 테스트·타입 검사·빌드와 배포 검사를 통과했다. 검증 이력은 [적용 결과 JSON](news-review16-acceptance.json)에 있다.

최종 전체 수집 시도에서는 부산 공식 수집원 일부의 연결 시간 초과를 별도로 관측했다. 이 외부 수집 문제를 이번 16건의 저장 성공으로 덮지 않고 JSON에 보존했다. 검토 결과의 최종 저장은 외부 수집과 분리해 기존 수집 잠금 아래 수행했다. `scripts/persist_review_sources.ts`는 준비된 검증 결과만 저장하며 AI·외부 뉴스 수집·Telegram은 실행하지 않는다.
