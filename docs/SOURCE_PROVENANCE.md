# Reference material and publication scope

This private development snapshot includes application source, plan images, project-level history, aggregate supply/type data, subscription comparison data and associated tests. Some source comments identify association-distributed or user-provided materials; those comments are provenance claims, not independently verified redistribution rights. Some historical records cite site roots rather than exact supporting documents. Do not treat all source availability, dates or rights as verified. Do not publish this repository or redistribute its reference materials without further review.

The included data is intended as project-level reference material, not an individual allocation register. No production database exports, personal account records, credentials, real environment files, operational logs or incident/audit reports are included.

General developer instructions and empty environment examples are provided. Build outputs and installed dependencies are excluded. GitHub changes do not automatically change production. Deployment and live collection require separate authorization.

Captured HTML fixtures use synthetic CSRF parameter/input values and telephone numbers. Parser output equivalence was checked locally, allowing only the intended phone-number substitution in extracted text; 79 collector regressions passed. These fixtures are test input, not live credentials.
