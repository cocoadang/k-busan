# 실제 문서 비교 결과 (2026-11-15)

부산 촉진3 조합의 공개 입찰 공고 원본 PDF 2건과 그중 첫 PDF를 이미지로 렌더링한 OCR 입력 1건을 사용했다. 독립 문서는 2건이며 총 3종 입력을 모델별 두 번씩, 6회 호출했다. Gemini 3.8 Flash와 OpenAI GPT-6.1 Sol에 같은 원문·지시·출력 구조를 주고 low 추론 설정으로 비교했다. OpenAI는 기존 K-news 키를 사용했다. 원문 다운로드 주소와 파일 SHA256, 응답·사용량은 인접 JSON에 보존했다.

| 항목 | Gemini 3.8 Flash | OpenAI GPT-6.1 Sol |
|---|---:|---:|
| 사실 필드 일치 | 54/54 (100%) | 51/54 (94.4%) |
| 원문과 위치가 일치하는 인용 | 30/30 | 30/30 |
| 평균 API 응답 | 3.90초 | 3.50초 |
| 6회 토큰 사용량 기준 비용 추정 | $0.01445 | $0.01586 |
| 같은 길이 1,000회 환산 | $2.41 | $2.64 |
| 입력 캐시가 없는 경우 1,000회 | $2.41 | 약 $6.28 (캐시 쓰기 단가 적용) |

OpenAI는 PDF 응답 4회 중 3회에서 입찰 마감일은 맞췄으나 `11:00`을 누락했다. 두 모델 모두 협력업체·용역 입찰을 시공사 선정 확정으로 잘못 판단하지 않았고, 세대수·면적·현장설명회 일시와 금액 미기재도 맞췄다. OCR 입력은 두 모델 모두 18/18 필드를 맞췄다. 인용 일치는 숫자 필드와 인용의 의미적 연결까지 자동 보증하는 지표는 아니다.

응답 시간은 API 호출만 측정했다. 다운로드·PDF/HWP 변환·OCR·서버 기동 시간은 별도다. OpenAI 입력은 거의 전부 캐시 적중이었으므로 속도·비용을 신규 문서 전체에 그대로 일반화할 수 없다. 비용은 청구서가 아닌 사용량×공식 단가 추정이며 예비 실행·키 확인 요청·실패한 변환 시험 및 서버 비용은 포함하지 않았다. 비교 성공 실행 자체의 두 공급자 합계는 약 $0.03031이다. Gemini 단가는 2026-12-31까지의 단가이며 2027-01-01부터 인상 예정이다.

표본이 작고 입찰 공고에 한정되므로 일반적인 모델 순위로 해석하지 않는다. 현재는 Gemini를 기본으로 유지한다. OpenAI 전면 교체를 정당화할 품질·비용 개선은 이번 표본에서 확인되지 않았다. HWP/HWPX 형식 읽기 지원은 별도 변환 검증이며 이 모델 정확도 점수에 포함하지 않았다. 그림만 있는 HWP는 성공 처리하지 않고 재시도 후 확인 대기 상태로 남긴다.
